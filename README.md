# Contact Book

A simple Contact Book application built with Python using Object-Oriented Programming (OOP) and CSV file handling.

## Features

- Add new contacts
- Remove contacts
- Search contacts by name
- Edit contact information
- Display all contacts
- Save contacts to a CSV file
- Load contacts automatically when the program starts

## Contact Information

Each contact contains:

- Name
- Phone number
- Email
- Address

## Technologies

- Python
- Object-Oriented Programming (OOP)
- CSV
- Git & GitHub
